NSFWDL Video Downloader userscript

A free, open-source userscript that puts a Download button on adult video pages. Pick a real quality with its real file size and the MP4 goes straight to your browser's downloads: no new tab, no copied links, no pop-ups. Version 2.2.0, MIT licensed.

Install from Sleazy Fork Source on GitHub About the script on nsfwdl.com

What it does

  • Real qualities, real sizes. Every choice comes from the actual video (for example 720p · ~110 MB), measured by NSFWDL.
  • Live progress. Waiting, preparing with a real percentage, saved. The tab title shows the progress and a notification tells you when a file is ready.
  • Queue as many as you like. Four run at a time; the rest wait their turn and start on their own.
  • Download from thumbnails on listings, search results and profiles, without opening the video (desktop).
  • See what you already have. Videos you saved get a green outline on their thumbnails.
  • Phones too: Firefox or Edge on Android, Safari with the free Userscripts app on iPhone.

Install

  1. Install Tampermonkey or Violentmonkey (on iPhone: the Userscripts app for Safari).
  2. Open the script on Sleazy Fork and press Install. Updates arrive automatically.

Privacy

The script talks only to nsfwdl.com, and only after you click. It contains no analytics, ads or tracking code, and keeps its settings and the list of videos you saved in your userscript manager. The code is readable and unminified.
